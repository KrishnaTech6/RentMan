# Data stays on the phone, with a JSON file as the backup

There is no server, account or cloud sync. Backup is exporting one JSON file through the share sheet and importing it back, restored in a single transaction. This keeps renters' phone numbers and money records off any server and avoids running one, at the cost of no automatic multi-device sync. Adding sync later would mean a new storage layer, so this is the point to revisit if the landlord ever needs two devices.
